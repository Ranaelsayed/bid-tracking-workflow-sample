# Bid & Tender Tracking Workflow (Sample)

> **Illustrative sample.** All companies, tenders, amounts and dates are fictional. No real or confidential data is included.

A lightweight workflow for tracking tenders from discovery to submission and follow-up, as a checklist and a tracker template.

## What is inside

- `workflow.md`: the stages and checklist
- `tracker-sample.csv`: tracker with fictional entries

## Why it works

- One status per opportunity, so nothing is lost
- A go / no-go step before spending effort
- Deadlines and owners always visible
